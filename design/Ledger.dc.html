L
Ledger

Project cashbook, designed for daily use

Multi-tenant In/Out tracking per project. PKR only. Every screen below is specified at desktop (1440) and mobile (390). Tokens are CSS custom properties, layout is plain HTML and CSS, no component library.

Type  Public Sans · IBM Plex Mono for money
Accent  Ink blue, held apart from In/Out hues
Rows  44px, comfortable
Money  Full figures everywhere, never abbreviated
Entries  Append-only. No edit, no delete, ever

On the name: keeping “Ledger” as you asked. If you ever want a local-first alternative, Khata is the Urdu word for exactly this book and needs no explanation to a contractor in Lahore.
